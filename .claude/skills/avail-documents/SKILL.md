# Документы проекта AVAIL: технические правила для кода

**Статус: требования к будущим экспортам (фаза 5 — функционал редактора), не к текущему коду.** Сейчас EasySchematic
делает только схему сигналов; план расстановки, BoQ и BoM инженеры собирают вне редактора. Здесь — то, что код должен
соблюдать, когда начнёт их строить. Источник — действующие стандарты документов AVAIL (технические правила без
коммерческих данных).

**Не класть в репозиторий** (он публичный): прайс-листы и их файлы, цены, скидки, бюджетные оценки, карту вендоров и
условия поставок. Экспорт берёт цену из источника, который даёт сервер на время сборки документа; в коде и тестах —
только вымышленные примеры.

## 1. Цепочка

**Схема сигналов → План расстановки → BoQ (оборудование) → BoM (кабели и монтаж).**

- Схема (EasySchematic) — источник состава оборудования и связей: блоки устройств, порты, кабели.
- План расстановки — где стоит каждое устройство схемы и как идут трассы; даёт длины трасс.
- BoQ — оборудование по устройствам схемы (модель, артикул, количество, цена).
- BoM — кабели и монтажные материалы: метраж по связям схемы и длинам трасс плана, крепёж по устройствам.

Каждый следующий документ строится из предыдущих, а не вводится заново.

## 2. Коды устройств — общий ключ

Код устройства: **`<ТИП> <помещение>.<номер>`** — тип латиницей заглавными, пробел, номер помещения, точка, номер
устройства этого типа в помещении: `CAM 1.1`, `MIC 1.1`, `SPK 1.2`, `LCD 1.1`, `TLP 1.1`, `OCS 1.1`.
**Без подчёркивания** (старые документы писали `CAM_1.1` — при импорте приводить к `CAM 1.1`).

Код — ключ, связывающий все четыре документа: подпись блока на схеме, подпись символа на плане (на плане — только
код, без модели), колонка «Код» в BoQ и в расчёте кабеля BoM. Код уникален в проекте; переименование устройства
меняет его во всех документах сразу.

## 3. BoQ — 3 листа

1. **«Параметры»** — объект (помещение, этаж), дата источника цен, валюта, скидка (не заполняется в репозитории), строка
   на каждую TBD-позицию.
2. **«Спецификация оборудования»** — строки 1–3: заголовок листа, легенда, шапка; затем группы (заголовок группы на
   всю ширину) и строки данных; последняя — итого. Колонки: № · Код · Наименование · Модель / Исполнение · Part # ·
   Производитель · Ед. · Кол. · Цена · Сумма (`=Кол.×Цена`). Порядок групп для переговорной: источники сигнала,
   коммутация, аудио, сеть, отображение, управление, питание и датчики. Итого — `=SUM(<диапазон>)`, не перечисление
   ячеек; в тексте итого — список TBD-позиций, не вошедших в сумму. Закрепление строк до шапки.
3. **«Итого к заказу»** — плоский список для заказчика: No · Part # · Model · Brand · Description (EN) · Qty · Price ·
   SubTotal (`=Qty×Price`); строка 2 — название помещения; итого — `=SUM(<диапазон>)`; последняя строка — легенда цветов.

Description — на английском: из описания производителя (прайс или официальный сайт).

**Комплекты** (`docs/avail/kits.json`: артикул комплекта → компоненты с количеством; у компонента
`_avail.kit.kitPartNumbers`). Блоки схемы, которые составляют комплект целиком, дают в BoQ **одну строку комплекта**
(артикул комплекта, количество комплектов); компоненты сверх комплекта — **отдельные строки** своими артикулами.
Пример: на схеме матрица MX-0404-KIT-MATRIX и 4 × MX-KIT-RX, комплект MX-0404-KIT = 1 матрица + 3 приёмника →
1 × MX-0404-KIT и 1 × MX-KIT-RX. Удлинитель EX-70-H2L-TX + EX-70-H2L-RX → 1 × EX-70-H2L. Подбор — жадно, по
полным комплектам; код устройства (CAM 1.1…) у блоков сохраняется для плана и BoM.

## 4. BoM — 5 листов

1. **«Параметры»** — исходные данные формул: расстояние от коммутатора PoE до серверной, высота потолка, коэффициент
   запаса Cat6 (15 %), длина и ширина помещения, запас кабеля на концы. Формулы ссылаются на эти ячейки абсолютно.
2. **«Cat6 — LAN кабели»** — по строке на устройство: № · Код · Устройство · Тип PoE · `d_трассы, м` · База, м
   (формула) · К заказу, м (формула, с запасом, округление вверх до 5 м) · Примечание; итого метража и число бухт 305 м.
3. **«Кабели HDMI-USB-питание»** — № · Наименование · Арт./Модель · Длина · Кол-во · Статус · Примечание (видео,
   USB, аудио, питание).
4. **«Монтаж и материалы»** — № · Категория · Наименование · Арт./Тип · Кол-во · Ед. · Примечание (крепления устройств,
   LAN-коммутация, кабельные трассы, питание, крепёж; аксессуары крепления — отдельными строками).
5. **«Итого к заказу»** — сводная ведомость по секциям: Cat6, HDMI / USB, аудио, питание, монтаж, LAN-коммутация,
   трассы и крепёж; последняя строка — легенда цветов.

## 5. Палитра документов (BoQ и BoM — одна)

| Константа | HEX | Где |
|-----------|-----|-----|
| `BG_TITLE` | `1F4E79` | заголовок листа, итого, секции «Итого к заказу» |
| `BG_HDR` | `2E75B6` | шапка колонок, заголовки групп, легенда |
| `BG_GREEN` | `E2EFDA` | позиция подтверждена (цена из источника, «в спеке») |
| `BG_YEL` | `FFFFC7` | TBD / уточнить |
| `BG_DATA` | `FCE4D6` | строки расчёта Cat6 в BoM (всегда, независимо от статуса) |

Текст на тёмном фоне — белый; шрифт Calibri; сетка листа скрыта; границы ячеек тонкие светло-серые.

## 6. TBD — неизвестная цена

Цена не найдена в источнике → значение **`TBD`** (не 0 и не пусто), фон строки `BG_YEL`, текст цены красный
(`CC0000`). TBD-позиция не входит в сумму; итого прямо называет, что посчитано без TBD, а лист «Параметры» перечисляет
TBD-позиции. Подтверждённая цена — фон `BG_GREEN`.

## 7. План расстановки

- **Масштаб 1:100**: 1 единица плана = 1 см (1 м = 100 единиц). Строится внутри EasySchematic (принятое решение: не
  во внешних редакторах).
- Устройства — символы с подписью **кодом устройства** (без модели); зоны (потолок, стена, стол, стойка) различаются
  цветом.
- Трассы: периметральный лоток, спуски к устройствам, ветка к стойке, канал под столом; на каждом участке — подпись
  числа кабелей («4× Cat6A / 1× HDMI»).
- **Длина трассы `d_трассы`** — полный маршрут кабеля от коммутатора (PSW) до устройства по трассам плана, в метрах. Это
  вход для BoM: База = `d_трассы` + расстояние до серверной + длина помещения; К заказу = База × (1 + запас),
  округлённое вверх до 5 м. Экспорт BoM берёт `d_трассы` из плана по коду устройства.
